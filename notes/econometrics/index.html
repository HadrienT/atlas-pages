Studying a linear model.

A decision tree and a reference sheet for cross-section, panel and time-series regressions: the assumptions, the tests that check them, the tests on the parameters, when to go robust, and what to do when a test rejects. Built from Wooldridge, Introductory Econometrics, and Tsay, Analysis of Financial Time Series.

Decision tree

Answer each question and follow the branch. Each node says which test to run, its null hypothesis, and what to do with the result; the links lead to the reference sections below. "Show the whole tree" prints every branch at once.

The workflow in one page

The order matters: a test on the variance is meaningless if the mean is wrong, and a t test is meaningless if its standard error is wrong. Specification first, then exogeneity, then the second moments, then inference.

1 · Before estimating

  1. State the question: causal effect (ceteris paribus) or prediction? Only the first needs E(u|x) = 0.
  2. Write the population model and the sign you expect for each β.
  3. Look at the data: summary statistics, histograms (logs for skewed positive variables), scatter plots, missing values, outliers, units.
  4. Time series: plot every series, check stationarity (ADF + KPSS), seasonality, breaks.

2 · Estimate and check the mean

  1. OLS. Check signs, magnitudes, R², the number of observations actually used.
  2. Functional form: residual plots, RESET, logs, quadratics, interactions.
  3. Exogeneity: omitted variables, measurement error, simultaneity. Proxy, panel or IV if needed.
  4. Time series: strict or contemporaneous exogeneity, dynamics, cointegration.

3 · Check the second moments

  1. Heteroskedasticity: Breusch–Pagan, White. ARCH LM in time series.
  2. Serial correlation (time series, panel): Breusch–Godfrey, Ljung–Box on residuals.
  3. Choose the variance estimator: usual, HC, HAC, clustered. Or FGLS / WLS for efficiency.

4 · Infer and report

  1. t tests, confidence intervals, F / Wald / LM for joint hypotheses, using the chosen variance.
  2. Stability: Chow, sup-F, CUSUM; sub-samples.
  3. Robustness: alternative specifications, samples, estimators. Report the ones that disagree.
  4. Interpret magnitudes in the units of y, with the functional form in mind.

Assumptions and what they buy

Each property of OLS rests on a specific set of assumptions. Knowing which one fails tells you what is lost: bias, efficiency, or only the standard errors.

  • MLR.1–4: OLS is unbiased, E(β̂) = β.
  • MLR.1–5 (Gauss–Markov): OLS is BLUE, and Var(β̂_j) = σ² / [SST_j(1 − R_j²)] is valid.

Large samples W ch. 5

  • Consistency needs only E(u) = 0 and Cov(x_j, u) = 0 (MLR.4′), weaker than MLR.4.
  • Under MLR.1–5, β̂ is asymptotically normal: t and F are approximately valid without normality.
  • Inconsistency with one regressor: plim β̂₁ − β₁ = Cov(x₁, u) / Var(x₁).

Traps specific to time series

  • A lagged dependent variable always breaks strict exogeneity: OLS is biased in small samples but consistent under TS.3′.
  • Highly persistent (unit-root) series break TS.1′: the usual asymptotics fail.
  • Strict exogeneity is needed for FGLS corrections of serial correlation; HAC needs only TS.3′.

Reading a test. Not rejecting H0 is not evidence that H0 is true, only that the data cannot tell. Tests of assumptions have low power in small samples and reject trivial departures in huge ones: look at the size of the problem (plots, how much the standard errors change), not just the p-value.

Testing the parameters

Once the mean and the variance estimator are settled. Every formula below has a robust counterpart (next section); the SSR and R² forms are valid only under homoskedasticity.

One coefficient: the t test W ch. 4

t = (β̂_j − a_j) / se(β̂_j) ~ t(n−k−1)
  • Two-sided H1: reject if |t| > c, c = 1.96 at 5 % in large samples.
  • One-sided H1 (β_j > 0): c = 1.645 at 5 %; only if the sign was set before seeing the data.
  • p-value: the smallest level at which H0 is rejected.
  • Confidence interval: β̂_j ± c · se(β̂_j); it contains every a_j that a two-sided test would not reject.

A linear combination

H0: β₁ = β₂. Either compute se(β̂₁ − β̂₂) = √[se₁² + se₂² − 2·Cov(β̂₁, β̂₂)], or reparametrise:

θ = β₁ − β₂ ⇒ y = β₀ + θx₁ + β₂(x₁ + x₂) + … + u

and read the t test of θ directly. Same trick for a long-run propensity (sum of lag coefficients) or a predicted value at given x (centre the regressors at those values: the intercept is the prediction).

Several restrictions: the F test

F = [(SSR_r − SSR_ur)/q] / [SSR_ur/(n−k−1)] ~ F(q, n−k−1) F = [(R²_ur − R²_r)/q] / [(1 − R²_ur)/(n−k−1)]
  • q = number of restrictions. The R² form needs the same dependent variable in both models.
  • Overall significance: F = [R²/k] / [(1−R²)/(n−k−1)].
  • Variables can be jointly significant while each t is small (collinearity), and the reverse.
  • General linear restrictions (β₁ = 1, β₂ = 0): impose them, transform y, and compare SSR.

LM (score) test: only the restricted model W §5.2

  1. Estimate the restricted model, save ũ.
  2. Regress ũ on all regressors.
  3. LM = n · R²_ũ ~ χ²_q.

Useful when the unrestricted model is hard to estimate. Asymptotically equivalent to F.

Wald, LR, LM

  • Wald: unrestricted model only; W = (Rβ̂ − r)′ [R V̂ R′]⁻¹ (Rβ̂ − r) ~ χ²_q (W/q ≈ F). Plug in any V̂: robust, HAC, clustered. Not invariant to how a nonlinear restriction is written.
  • LR: both models, by maximum likelihood; LR = 2(ℓ_ur − ℓ_r) ~ χ²_q. Valid only if the likelihood is right (no robust version). Standard for ARMA / GARCH / probit.
  • LM: restricted model only.
  • For linear models with normal errors, W ≥ LR ≥ LM in finite samples.

Groups and breaks: Chow W §7.4

Interact every regressor with a group dummy d, and F-test all the d terms (intercept + slopes): k+1 restrictions. Testing only the slopes lets the intercept differ. With heteroskedasticity use the robust Wald version of the same test.

The robust variance (White, W §8.2)

Var̂(β̂_j) = Σᵢ r̂²_ij û²_i / SSR_j²

r̂_ij: residual of regressing x_j on the other regressors; SSR_j: its sum of squares. In matrix form, (X′X)⁻¹ X′diag(û²)X (X′X)⁻¹. HAC adds weighted autocovariance terms (Bartlett kernel, weights 1 − h/(g+1)).

Robust LM test (W §8.2)

  1. Restricted model, residuals ũ.
  2. Regress each excluded x_j on the included regressors, residuals r̃_j.
  3. Form the products ũ·r̃_j, j = 1 … q.
  4. Regress 1 on them, no intercept: LM = n − SSR₁ ~ χ²_q.

Rules of thumb

  • With a cross-section of any size, reporting robust SE costs little; many papers do so by default.
  • If robust and usual SE differ a lot, the heteroskedasticity is real; it can also signal a misspecified mean.
  • Robust SE fix inference, not bias. They do nothing for an endogenous regressor.
  • Clustering: cluster at the level at which the regressor of interest varies, or the treatment was assigned.

Including an irrelevant variable costs only variance; omitting a relevant one costs bias.

Variance of a coefficient

Var(β̂_j) = σ² / [SST_j (1 − R_j²)]
  • σ² larger → less precise; more variation in x_j (SST_j, grows with n) → more precise.
  • R_j²: R² of x_j on the other regressors. VIF_j = 1/(1 − R_j²).
  • σ̂² = SSR / (n − k − 1), the standard error of the regression is σ̂.

Goodness of fit

  • R² = 1 − SSR/SST; never falls when a regressor is added.
  • R̄² = 1 − [SSR/(n−k−1)] / [SST/(n−1)]; rises when the added variable has |t| > 1.
  • A low R² does not bias β̂; a high R² does not make it causal.
  • To compare log y with y: predict y from the log model, ŷ = α̂₀ · exp(m̂), with m̂ the fitted log y and α̂₀ = mean of exp(û) (Duan smearing), and take the squared correlation of ŷ with y.
  • Information criteria (smaller is better): AIC = ln(SSR/n) + 2(k+1)/n, BIC = ln(SSR/n) + (k+1) ln n / n.

Dummies W ch. 7

  • g categories → g − 1 dummies with an intercept (the omitted one is the base group).
  • Ordinal variable: dummies for each level, then F-test that the effects are linear.
  • Difference-in-differences: y = β₀ + δ₀·after + β₁·treated + δ₁·after·treated + u; δ₁ is the effect, under parallel trends.
  • LPM: binary y; β_j is a change in probability; predictions can leave [0, 1]; always robust SE. Probit / logit for the shape, with average partial effects.

Proxies and lagged dependent variables W §9.2

A proxy z for an unobserved x* removes the bias if, once z is controlled for, x* is unrelated to the other regressors. A lagged y (from an earlier period of a cross-section) controls for history that drives the current outcome.

Prediction intervals

The variance of a prediction error adds the error variance to the estimation variance: se(ê⁰) = √[se(ŷ⁰)² + σ̂²]. Get se(ŷ⁰) by centring the regressors at x⁰ and reading the intercept's standard error.

Endogeneity and instrumental variables

When E(u|x) = 0 is not credible and no panel is available. W ch. 15–16.

A valid instrument z

  1. Exogenous: Cov(z, u) = 0. Not testable with one instrument per endogenous variable; argue it.
  2. Relevant: Cov(z, x) ≠ 0, given the other exogenous variables. Testable: first-stage F.

Simple IV: β̂₁ = Cov(z, y) / Cov(z, x). A weak instrument amplifies any small correlation between z and u: plim β̂_IV = β₁ + [Corr(z,u)/Corr(z,x)]·(σ_u/σ_x).

2SLS

  1. First stage: regress x on z and all exogenous regressors, save x̂.
  2. Second stage: regress y on x̂ and the exogenous regressors.

Use a 2SLS routine: the second-stage SE from step 2 by hand are wrong. 2SLS is consistent, biased in finite samples (towards OLS), and its SE are larger than OLS's; R² has no meaning.

The tests, in order

  1. Relevance: first-stage F (robust). F > 10 as a minimum.
  2. Endogeneity: Hausman regression form (add v̂, t test).
  3. Overidentification (if #IV > #endog.): Sargan n·R², Hansen J under heteroskedasticity.
  4. Heteroskedasticity: BP on 2SLS residuals, or simply robust SE.
  5. Serial correlation (time series): BG on 2SLS residuals with the 2SLS fitted values.

Simultaneous equations W ch. 16

  • Each structural equation needs an excluded exogenous variable that appears elsewhere in the system (order condition), with a nonzero coefficient there (rank condition).
  • Estimate each identified equation by 2SLS.
  • In time series, lagged variables are often used as instruments; they are valid only if the errors are not serially correlated.

Time series: stationarity, ACF, ARMA

The univariate toolkit of Tsay ch. 1–2, and Wooldridge ch. 11 for the regression side.

Returns T ch. 1

  • Simple: R_t = P_t / P_{t−1} − 1; log: r_t = ln(1 + R_t) = ln P_t − ln P_{t−1}.
  • Multi-period log returns add up; simple returns compound. Portfolio returns are linear in simple returns.
  • Stylised facts: little serial correlation, heavy tails (excess kurtosis), volatility clustering, leverage (volatility rises after falls).

Stationarity and weak dependence

  • Weakly stationary: constant mean and variance, Cov(r_t, r_{t−ℓ}) = γ_ℓ depends only on ℓ.
  • Weakly dependent: correlation dies out as ℓ grows (AR(1) with |ρ| < 1, any MA). A random walk is neither.
  • AR(1) y_t = ρy_{t−1} + e_t: stationary iff |ρ| < 1; ρ = 1 is a unit root.

Sample ACF

  • ρ̂_ℓ = Σ (r_t − r̄)(r_{t−ℓ} − r̄) / Σ (r_t − r̄)².
  • For i.i.d. data, ρ̂_ℓ ≈ N(0, 1/T): bands ±2/√T.
  • Bartlett, for an MA(q): Var(ρ̂_ℓ) ≈ (1 + 2Σ_{i=1}^{q} ρ_i²)/T for ℓ > q.
  • Ljung–Box Q(m) tests many lags at once; m ≈ ln T (Tsay).

AR(p) T §2.4

  • r_t = φ₀ + φ₁r_{t−1} + … + φ_p r_{t−p} + a_t; mean φ₀ / (1 − φ₁ − … − φ_p).
  • Stationary iff all roots of 1 − φ₁z − … − φ_p z^p are outside the unit circle.
  • AR(2) with complex roots: cycles of average length 2π / cos⁻¹[φ₁ / (2√−φ₂)].
  • Order: PACF cuts off after p; or AIC/BIC over p.
  • AIC(ℓ) = ln σ̃²_ℓ + 2ℓ/T, BIC(ℓ) = ln σ̃²_ℓ + ℓ ln T / T.

MA(q) and ARMA(p,q)

  • MA(q): r_t = c₀ + a_t − θ₁a_{t−1} − … − θ_q a_{t−q}, always stationary, finite memory: ACF zero after lag q; forecasts revert to the mean after q steps.
  • Invertible if the roots of the MA polynomial are outside the unit circle.
  • ARMA: both ACF and PACF tail off; use the EACF or information criteria. Common AR and MA roots cancel: keep the model small.
  • Estimate by conditional or exact likelihood.

Seasonal models T §2.8

  • Seasonal difference (1 − B^s) x_t, s = 4 quarterly, 12 monthly.
  • Airline model: (1 − B)(1 − B^s) x_t = (1 − θB)(1 − ΘB^s) a_t.
  • Deterministic seasonality: seasonal dummies in a regression.

Forecasting

  • ℓ-step forecast of a stationary ARMA converges to the unconditional mean; its error variance to the unconditional variance.
  • MA representation r_t = μ + Σ ψ_i a_{t−i}: forecast error variance σ²(1 + ψ₁² + … + ψ²_{ℓ−1}).
  • Evaluate out of sample (rolling origin); never select the model on the test sample.

Long memory T §2.11

ACF decays hyperbolically, not exponentially; typical for absolute or squared returns. Fractional differencing (1 − B)^d, −0.5 < d < 0.5: ARFIMA.

Unit roots, spurious regressions, cointegration

W ch. 11 and 18, T §2.7 and ch. 8. The single most common way time-series regressions go wrong.

ADF regression

Δx_t = α + δt + θx_{t−1} + Σ_{i=1}^{p} γ_iΔx_{t−i} + e_t, H0: θ = 0
  • Compare the t of θ̂ with the Dickey–Fuller critical values (not ±1.96): −2.86 at 5 % with a constant, −3.41 with a trend.
  • Constant only for series without a trend; add the trend δt for trending series. Wrong choice → wrong size or low power.
  • Choose p by AIC/BIC, or start large and drop insignificant lags.
  • Low power: a near-unit-root stationary series (ρ = 0.95) is hard to distinguish from a random walk.

Spurious regression

  • Two independent random walks regressed on each other: t statistics reject far more than 5 % of the time, R² does not go to 0 (Granger–Newbold; Phillips).
  • Symptoms: high R², very low DW, residuals with a unit root.
  • Trending but stationary series: add a time trend instead.

Cointegration

  • y_t and x_t are I(1) but y_t − βx_t is I(0): a long-run equilibrium (spot and futures, yields of nearby maturities, pairs of stocks).
  • Engle–Granger: OLS in levels, ADF on residuals with EG critical values. β known in advance (e.g. β = 1)? Test the spread with ordinary ADF.
  • OLS β̂ is superconsistent, but its t statistic is not usable; use DOLS (add leads and lags of Δx) with HAC SE for inference on β.
  • Johansen: the rank of Π in Δx_t = Πx_{t−1} + Σ Γ_iΔx_{t−i} + e_t; rank 0: no cointegration, VAR in differences.

Error-correction model

Δy_t = α₀ + γ₀Δx_t + δ(y_{t−1} − βx_{t−1}) + u_t

δ < 0: the speed at which deviations close (half-life ln 0.5 / ln(1 + δ)). All terms are I(0), so t and F are standard. Granger representation theorem: cointegration ⇔ an ECM exists.

Unit roots in finance

  • Log prices ≈ random walk; returns ≈ white noise in the mean.
  • Interest rates, spreads, volatility: very persistent; tests often do not reject even when theory says mean reversion.
  • Pairs trading relies on cointegration; check it out of sample, as relations break.

Regression with time series

W ch. 10–12 and T §2.9: static models, distributed lags, trends, and serially correlated errors.

Model types

  • Static: y_t = β₀ + β₁z_t + u_t, contemporaneous effect.
  • Finite distributed lag: y_t = α + δ₀z_t + δ₁z_{t−1} + δ₂z_{t−2} + u_t. Impact propensity δ₀, long-run propensity δ₀ + δ₁ + δ₂.
  • Dynamic / ARDL: lags of y too. Long-run effect Σδ / (1 − Σφ).
  • Lags of z are often collinear: test the LRP (reparametrise) rather than each δ.

Trends and seasonality W §10.5

  • Two trending series correlate even when unrelated: include t (or t, t²).
  • With a trend, R² is inflated by it; detrend y to report a meaningful R².
  • Seasonal dummies; test jointly. Seasonally adjusted data: no dummies needed.
  • Log of a trending variable: a linear trend coefficient is the average growth rate.

Serial correlation: what it does

  • Strictly exogenous x: OLS unbiased and consistent; usual SE wrong (too small when ρ > 0 and x is positively correlated over time).
  • Lagged y and correlated errors: OLS inconsistent.
  • R² is still a valid measure if the data are stationary and weakly dependent.

Testing (W §12.2)

  1. AR(1), strictly exogenous x: û_t on û_{t−1}; t test.
  2. General x: û_t on x_t and û_{t−1}; robust t test.
  3. AR(q): û_t on x_t and q lags; F, or Breusch–Godfrey LM.
  4. Seasonal (quarterly): û_t on x_t and û_{t−4}.

Correcting

  • HAC (Newey–West) with OLS: needs only TS.3′.
  • Prais–Winsten / Cochrane–Orcutt FGLS: strict exogeneity; efficient.
  • Differencing: when ρ is near 1, first differences remove most serial correlation.
  • Dynamic completeness: add lags until errors are white noise.
  • Regression with ARMA errors (T): joint MLE of regression and error process.

Predictive regressions in finance

  • Returns on lagged persistent predictors (dividend yield, rates): β̂ biased in small samples when innovations correlate (Stambaugh).
  • Overlapping long-horizon returns: HAC with g ≥ h − 1, or non-overlapping data; t statistics are still oversized.
  • Out-of-sample R² against the historical mean is the honest test.

Volatility: ARCH and GARCH

T ch. 3. The mean equation removes linear dependence; the volatility equation describes the conditional variance of what remains.

The procedure (T §3.3)

  1. Build a mean equation (often a constant or a low-order ARMA); test residuals for serial correlation.
  2. Test the residuals a_t for ARCH effects (Ljung–Box on a_t², Engle LM).
  3. Specify a volatility model; PACF of a_t² can suggest an ARCH order; GARCH(1,1) is the usual start.
  4. Estimate mean and volatility jointly by MLE.
  5. Check the standardised residuals; refine.

ARCH(m) and GARCH(1,1)

a_t = σ_t ε_t, σ²_t = α₀ + α₁a²_{t−1} + … + α_m a²_{t−m} σ²_t = α₀ + α₁a²_{t−1} + β₁σ²_{t−1}
  • α₀ > 0, α₁, β₁ ≥ 0, α₁ + β₁ < 1. Unconditional variance α₀ / (1 − α₁ − β₁).
  • Persistence α₁ + β₁; half-life of a shock ln 0.5 / ln(α₁ + β₁).
  • Forecasts revert to the unconditional variance at rate α₁ + β₁.
  • Implies fat tails even with normal ε.

Variants

  • IGARCH: α₁ + β₁ = 1, shocks persist (RiskMetrics EWMA with λ = 0.94 is a special case without α₀).
  • GJR / TGARCH: σ²_t = α₀ + (α₁ + γN_{t−1})a²_{t−1} + β₁σ²_{t−1}, N = 1 if a_{t−1} < 0. γ > 0: leverage.
  • EGARCH: models ln σ²_t, so no positivity constraints; asymmetric response to the sign of ε.
  • GARCH-M: σ_t (or σ²_t) in the mean equation: a risk premium.
  • Innovations: normal, Student-t (ν estimated), skewed-t, GED.

Checking the model

  • ã_t = a_t / σ̂_t should be i.i.d.: Ljung–Box on ã_t and on ã_t².
  • Sign-bias test on ã_t² for missed asymmetry.
  • QQ plot against the assumed distribution; KS or JB on ã_t.
  • Compare models by AIC / BIC and by out-of-sample volatility forecasts against realised variance (QLIKE or MSE loss).
  • Use QMLE (sandwich) standard errors if the innovations are not what the likelihood assumes.

Several series and forecasting

T ch. 8 for VAR and cointegration in systems; forecast evaluation for any model.

VAR(p)

  • x_t = φ₀ + Φ₁x_{t−1} + … + Φ_p x_{t−p} + a_t, each equation by OLS.
  • Order: AIC, BIC, HQ, or sequential LR tests of Φ_p = 0.
  • Stationary if all roots of |I − Φ₁z − … − Φ_p z^p| = 0 lie outside the unit circle.
  • Residual check: multivariate Portmanteau Q_k(m) ~ χ²(k²(m − p)) asymptotically.

Granger causality and impulse responses

  • x Granger-causes y if lags of x help predict y given lags of y: Wald / F test of the x lags in the y equation.
  • Impulse responses trace a shock through the system. Cholesky ordering: the first variable reacts only to its own shock on impact. Results depend on the order.
  • Forecast error variance decomposition: the share of each shock in the forecast variance.

Forecast evaluation

  • Split by time, never randomly. Rolling or expanding windows.
  • Losses: RMSE, MAE; QLIKE for volatility.
  • Diebold–Mariano: equal accuracy of two forecasts (HAC variance of the loss difference). For nested models use Clark–West.
  • Benchmarks: random walk for prices, historical mean for returns, EWMA for volatility.

Pitfalls

The mistakes that survive every test above.

Inference

  • Statistical significance ≠ economic importance: always read the magnitude and the confidence interval.
  • "Not significant" ≠ "no effect": a wide interval that includes large values is not evidence of zero.
  • Testing many specifications and reporting the significant one: the 5 % level no longer means 5 %. Bonferroni (α/m) or a pre-specified model.
  • A one-sided test chosen after seeing the sign of β̂.

Specification

  • Bad controls: controlling for a variable that is itself caused by x removes part of the effect you want.
  • Comparing R² of models with different dependent variables (y vs log y).
  • Extrapolating a quadratic beyond the turning point or the data range.
  • Interpreting the main effect in a model with interactions as an average effect.

Time series

  • Regressing levels of I(1) series without checking cointegration.
  • Durbin–Watson with a lagged dependent variable.
  • FGLS when x is not strictly exogenous.
  • Look-ahead bias: using data not available at forecast time (revised macro data, survivorship-free universes).
  • Selecting the model on the whole sample, then "testing" it out of sample.

Causality

  • Granger causality is predictive, not causal.
  • IV estimates the effect for the units moved by the instrument (LATE), not necessarily the average effect.
  • An overidentification test that does not reject does not prove instruments are valid.
  • Robust standard errors do not fix endogeneity.
